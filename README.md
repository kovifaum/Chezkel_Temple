# תבנית הבית – יחזקאל מ–מד בתלת־ממד

אתר אינטראקטיבי שבו כל פסוק ומילה בפרקים מ–מד של ספר יחזקאל (חזון הבית) מוצגים כ**מודל תלת־ממדי** של המקדש.
לחיצה על פסוק מזיזה את המצלמה אל הנושא שהפסוק מתאר, מאירה את החלקים הרלוונטיים, מציגה את המידות (באמות) –
ומתחתיו לשוניות עם הביאורים והשיטות האחרות.

> *An interactive 3D site for Ezekiel 40–44 (the vision of the temple). Click a verse or a word and the 3D model of
> the temple focuses on what the text describes; tabs next to it show the Gra's explanation (from the attached book),
> Rashi, Radak, Metzudat David, Malbim, Abarbanel, Targum Jonathan, the Second-Temple comparison (Mishnah Middot),
> and several readings that can be switched on in 3D.*

## הפעלה

האתר הוא קובץ HTML יחיד, עצמאי (JS, CSS והנתונים בפנים), ולכן אפשר:

* לפתוח את `index.html` ישירות בדפדפן (גם ללא שרת, גם ללא רשת).
* להעלות ל-GitHub Pages / כל אחסון סטטי.

## פיתוח

```bash
npm install          # three + esbuild
npm run build        # בונה index.html מ-src/ ומ-data/
npm run dev          # בנייה מחדש בכל שינוי
npm run serve        # שרת מקומי http://localhost:8080
npm run fetch-data   # מושך מחדש את הפסוקים והפירושים מספריא (python3)
```

מבנה:

```
src/engine/    מנוע התלת־ממד (Three.js): במה, חומרים, איחוד גיאומטריה, שכבת מידות
src/model/     בניית המקדש – כל מידה באמות, עם הפניה לפסוק (dims.js, gate.js, court.js, inner.js, house.js, altar.js, ch42.js …)
src/content/   מיפוי כל 153 הפסוקים לסצנה (scenes4x.js), הסבר כל חלק בכל פסוק (parts4x.js), מילון מילים, ביאור הגר״א, הערות, שיטות, משנה מידות
src/ui/        ממשק: טקסט, כרטיס לשוניות, אפקטים (כבוד ה׳, דלתות, צליל)
data/          פסוקים ופירושים לכל פרק (JSON, מספריא)
tools/         משיכת נתונים, בניית משנה מידות, ובדיקת חלקי הפסוקים (validate_parts.mjs – כל פסוק מכוסה בחלקים, וכל תג/מידה קיימים במודל)
```

* **פירושים** – רש״י (מהדורה מנוקדת, CC BY), רד״ק, מצודת דוד וציון, מלבי״ם, אברבנאל, תרגום יונתן – ספריא.

* פרקים מב–מד אינם בספר המצורף: הגיאומטריה נבנתה מן הפסוקים ומפירושי הראשונים, ומקומות שהושלמו מסומנים באתר כ״השלמה״.
